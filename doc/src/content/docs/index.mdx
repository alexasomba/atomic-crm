title: Atomic CRM
description: Build and run Atomic CRM with Vite+ and Cloudflare.
---

Atomic CRM is a React 19 CRM using Vite+, TanStack Router, TanStack Query,
Base UI, Hono, Cloudflare D1, Drizzle, Better Auth, R2, Workers AI, and Cloudflare
Email Service.

## Local development

```sh
vp install
cp .dev.vars.example .dev.vars
pnpm run worker:types
pnpm run auth:generate
pnpm run db:check
pnpm run db:generate
pnpm run d1:migrate:local
vp run dev:all
```

The frontend runs on `http://localhost:5173`; the local Worker runs on the
Wrangler port shown in its output. Use `vp run dev:demo` for FakeRest data.

## Validation

```sh
vp check
vp test
vp build
wrangler deploy --dry-run --config wrangler.staging.jsonc
```

Staging uses `pnpm run data:seed:staging:reset`, `pnpm run auth:bootstrap:staging`,
`pnpm run smoke:staging`, and the credential-gated
`pnpm run smoke:staging:browser`. No production resources are modified by
these commands.
