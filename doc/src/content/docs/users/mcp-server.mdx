---
title: MCP Server
description: This document explains how to use MCP Server in Atomic CRM.
---

You can interact with the data stored in your Atomic CRM instance using the
in-repo MCP server. It is a thin authenticated wrapper over the same Cloudflare
Worker APIs that CopilotKit uses (`/api/contacts`, `/api/leads/top`,
`/api/contacts/:id/contract`, `/api/crm/tasks`).

## Local development

Start the Worker (and optionally MCP) with:

```sh
vp run dev:cloudflare
# optional MCP sidecar
vp run dev:all
```

The MCP endpoint listens at `http://localhost:3108/mcp` by default. Point it at
the Worker with `COPILOT_CRM_ORIGIN` (defaults to `http://127.0.0.1:8787`) and
authenticate with `MCP_AUTH_COOKIE` or `MCP_AUTH_BEARER`.

## Tools

Once authenticated, you can ask an MCP client to:

- Search contacts stored in D1
- List top leads by lead score
- Load a contact's stored contract text
- Create a follow-up task on an existing contact

Do not invent CRM record ids. Search first, then mutate.

The earlier Marmelab `atomic-crm-mcp` package and the markdown contract
analyzer are not the source of truth for this Cloudflare deployment.
