---
title: Custom fields
---

Custom fields are regular columns in the Drizzle SQLite schema. Add the field to
the relevant table in `server/db/schema.ts`, update the domain type and form,
then generate and review a Drizzle migration:

```sh
pnpm run db:check
pnpm run db:generate
pnpm run d1:migrate:local
```

Update Hono validation and the data-provider mapping when the field is exposed
through the API. Add a deterministic fixture value if the field is required by
the FakeRest demo.
