---
title: Architecture choices
---

Atomic CRM uses a Cloudflare-native backend. Hono provides the typed HTTP
boundary, D1 stores CRM and Better Auth data, Drizzle owns migrations, R2 stores
attachments and raw inbound mail, and Queues process MIME work asynchronously.

Hono authentication middleware replaces database row-level policies. Service
modules enforce authorization and use D1 batch statements for related writes.
FakeRest is isolated to demo mode and is not used by the Cloudflare runtime.
