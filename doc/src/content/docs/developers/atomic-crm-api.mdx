---
title: Atomic CRM API
---

The Hono Worker exposes the authenticated CRM API under `/api/crm`, Better Auth
under `/api/auth`, R2 attachment routes, inbound-email operations, and the
native CopilotKit route at `/api/copilotkit`.

All browser requests use same-origin cookies in staging. Local requests should
use the Vite proxy or set `VITE_CLOUDFLARE_API_URL` to the Worker origin.
