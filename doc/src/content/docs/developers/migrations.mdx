---
title: Database migrations
---

The application schema lives in `server/db/schema.ts`; Better Auth owns the
generated `server/db/auth-schema.ts`. Drizzle v1 RC is the migration source of
truth.

```sh
pnpm run auth:generate
pnpm run db:check
pnpm run db:generate
pnpm run d1:migrate:local
```

Review generated SQL before applying it to staging with
`pnpm run d1:migrate:staging`. Run `pnpm run db:up` when upgrading Drizzle
migration metadata.
