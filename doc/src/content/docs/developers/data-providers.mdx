---
title: Data providers
---

Cloudflare is the application data provider. The frontend calls the Hono API,
which authenticates with Better Auth and reads D1 through Drizzle. Files use R2.

FakeRest remains available for demos and isolated UI work:

```sh
vp run dev:demo
```

The provider contract is implemented in
`src/components/atomic-crm/providers/cloudflare/dataProvider.ts`. Keep custom
resource methods aligned with the shared `CrmDataProvider` type.
