---
title: Deploying Atomic CRM
---

Local and staging deployment use Wrangler and Vite+:

```sh
vp check
vp test
vp build
wrangler deploy --dry-run --config wrangler.staging.jsonc
pnpm run deploy:staging
```

Set `BETTER_AUTH_SECRET` with Wrangler secrets and keep credentials out of
source. Apply D1 migrations before a Worker deployment. The staging Worker is
`atomic-crm-staging.gittech.workers.dev`; production cutover is intentionally
outside this repository workflow.
