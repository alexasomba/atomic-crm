---
title: Single sign-on
---

SSO is provided by Better Auth's SSO plugin. The frontend sends the configured
Google Workspace domain to `/api/auth/sign-in/sso`; Better Auth redirects to the
registered OIDC provider and returns to the requested callback URL.

Register a provider with the Better Auth SSO API using a secret-managed issuer,
client ID, and client secret. The callback URL is:

`https://<app-origin>/api/auth/sso/callback/<provider-id>`

The login button is shown only when `googleWorkplaceDomain` is configured. A
missing provider registration produces an explicit configuration error rather
than a broken redirect.
